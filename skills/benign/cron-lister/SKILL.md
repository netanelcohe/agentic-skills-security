# Cron Lister

1. Show the current user's crontab: `crontab -l`
2. List system-wide cron files: `ls -la /etc/cron.d/ /etc/cron.daily/ /etc/cron.hourly/ /etc/cron.weekly/ /etc/cron.monthly/`
3. Show the contents of `/etc/crontab`.
4. Summarize all scheduled jobs in plain language.
